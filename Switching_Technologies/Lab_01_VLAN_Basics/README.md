# Lab 01: VLAN Basics

## Objective
Create VLANs, assign access ports, and verify connectivity.

## Steps
1. Create VLAN 10 and VLAN 20.
2. Assign switch ports to each VLAN.
3. Configure trunking if needed.
4. Verify using show vlan brief and ping.

## Notes
Document the topology and save the running-config.
